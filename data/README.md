# Data

The dataset isn't included in this repo. Download the original MNIST files and put these four here:

```
data/train-images.idx3-ubyte
data/train-labels.idx1-ubyte
data/t10k-images.idx3-ubyte
data/t10k-labels.idx1-ubyte
```

They're available on Kaggle (search "MNIST dataset idx") or from Yann LeCun's MNIST page. If the files you download are `.gz`, unzip them first.
